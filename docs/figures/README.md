# Documentation figure attribution

This directory contains project-authored equations and visualizations plus
derived diagnostic galleries. It does not contain raw third-party raster or map
data. Source licenses and copy-ready attribution are documented in
[`docs/data-licenses.md`](../data-licenses.md).

For a derived map or raster visualization, keep the applicable source credit in
the caption or immediately adjacent to the image. In particular:

- VIIRS-based images should identify NASA VNP46A2 Collection 2 and its DOI.
- Sentinel-derived images must say `Contains modified Copernicus Sentinel data
  2024`; Cloud Score+ use also requires CC BY 4.0 attribution.
- Overture/OSM-derived images should say `© OpenStreetMap contributors, Overture
  Maps Foundation` and link the ODbL/source notices.
- JRC-derived maps should say `Source: EC JRC/Google`.

Purely project-authored operator-equation images contain no third-party data and
need only the repository citation/license.
